# Verification

Tested on 2026-09-27 with the repository's Halo 2.26 development container at localhost:8090 and Corretto 21. The plugin was built and loaded through `./gradlew haloServer` and `./gradlew reloadPlugin`. Browser checks used isolated agent-browser sessions.

## Automated checks

- `./gradlew build`: 29 Java tests, no failures. Includes default-off policy before DNS, normalized exact hosts, empty whitelist, redirect rejection, fresh Console reads versus cached reads, and preserving HTTP policy errors wrapped by WebClient.
- `pnpm --dir packages/ui type-check`: passed.
- `pnpm --dir packages/hyperlink-card check`: passed, no warnings.
- ESLint on UI and Web Component sources: no errors; one generated-file warning for an unused eslint-disable directive in the generated API index.
- Prettier on changed frontend files and generated client: passed.
- `openspec validate secure-link-card-fetching --strict` and `git diff --check`: passed.
- Console API client generated by `./gradlew generateApiClient`, then formatted with Prettier. No lockfile hand edits.

## Running-service API checks

- Anonymous Console access redirects to login; a logged-in editor without the permission receives 403.
- Administrator and editor granted the fetch template receive 200 independently of public settings.
- Public fetching disabled: 403. Enabled without whitelist: 200 for example.com.
- Private address: 400. Enabled empty whitelist: 403.
- Exact normalized EXAMPLE.COM. entry allows example.com; subdomains and other hosts receive 403.
- Real httpbin.org redirect to an unlisted example.com is rejected with 403.
- The GET collection route uses the `list` RBAC verb; this was verified with a non-administrator account.

## Browser checks

- Administrator converts a link to a block card: one Console request; metadata and snapshot marker written automatically.
- Authorized non-administrator converts a link to an inline card in SinglePage: one Console request and saved metadata.
- Unauthorized editor can convert and manually edit; refresh button is disabled with an authorization explanation, and no metadata request is sent.
- Block-to-inline conversion preserves all custom attributes and snapshot mode.
- Saved Post content contains the snapshot marker in both raw and rendered content. Reopening the editor retains metadata and makes no link-detail requests.
- Explicit refresh replaces old metadata and a single undo restores it, including removing the new snapshot marker from a refreshed legacy card.
- Editing a URL does not fetch until Apply. Applying clears stale metadata and fetches the new URL; one undo restores the old URL and metadata.
- During a delayed real request, selecting another card still updates only the original card. Deleting/replacing the original node prevents the late response from overwriting the replacement.
- Public page with online fetching disabled renders partial/static and legacy cards without metadata requests.
- With online fetching enabled, two legacy fixtures send two public requests while block and inline snapshot fixtures send none; saved titles remain unchanged.
- Public request failure preserves custom title and a clickable link.
- Settings UI conditionally exposes the whitelist toggle and host list; saving example.com permits that host and denies others.

Screenshots are under `build/e2e/`: denied-editor.png, authorized-inline-editor.png, static-cards.png, fetch-settings.png. Temporary E2E users/content are removed and the original plugin configuration is restored after verification.

No bulk migration is included. Existing cards without saved metadata can degrade to basic links until manually refreshed or public compatibility fetching is enabled.

## Review regression fixes

- `node packages/ui/tests/insert-card.mjs`: passed using the installed ProseMirror dependencies. Covers actual inserted-node identity, adjacent inline cards, following block paragraphs, and preserving neighbours after automatic metadata updates and undo.
- Rebuilt and hot-reloaded on Halo 2.26. Real editor conversion requests only the inserted inline card URL, preserves the adjacent card's manual title, and undo restores the original link. A block conversion followed by another paragraph now fetches once.
- Applying two URLs successively in the same open popup fetches each once; undo restores the first URL and metadata.
- Both running Web Components keep saved titles and clickable links visible during browser-simulated pending requests and after rejection.
- Temporarily malformed fetch settings now return 403 instead of 500; original settings restored. Added an endpoint test proving no parser invocation when settings fail.
- Vue type checking, Svelte checking, changed-source ESLint, build and Java tests passed. Temporary browser-created Post was deleted and the isolated browser session closed.
